# 개인 스킬 설치 보완 계획

사용자 추가 요청: 현재 열린 무료 Claude Desktop 일반 채팅에서 연결 가능 여부를 확인하고, Codex/Claude Code에서 스킬로 사용 가능하게 한다.

1. 기존 Codex 플러그인의 `session-bridge` 스킬과 실제 MCP 도구 호출을 확인한다.
2. 검증된 동일 SKILL.md를 Claude Code 개인 스킬 디렉터리에 설치하고 공식 CLI로 사용자 범위 MCP를 등록한다. 기존 동명 설치는 덮어쓰지 않는다.
3. 일반 Claude Desktop MCP 설정을 원본 byte backup 후 병합한다. `session-bridge` 외 설정은 의미상 동일한지 확인한다. 계정 정보나 기존 서버 비밀은 출력하지 않는다.
4. 실제 사용자의 홈 경로를 지정한 서버 기동, 도구 목록, 현재 Codex 세션 읽기로 연결 명령을 검증한다. 앱 재시작 및 실제 Claude 채팅에서의 도구 호출은 별도 확인 단계로 명시한다.
5. README에 직접 스킬 호출, 영구 설치, 일반 채팅 연결의 범위를 기록하고 독립 리뷰한다.

런타임과 스킬 본문은 이미 검증된 구현을 사용한다. 일반 Claude 채팅을 원본으로 읽는 기능은 추가하지 않는다. 구매, 모델 자동 실행, 사용량 초기화는 수행하지 않는다.

독립 계획 리뷰: `desktop_support_check` — **APPROVED**. 개인 스킬의 독립성, 공식 설치 경로와 호출명, 기존 설정 보존, 실제 Claude UI 검증과 서버 검증 구분을 확인했다.
